# 0.2.0-alpha — 任务列表与界面复核

## 数据和行为

- 默认隐藏完成、取消、归档的任务；状态筛选保留独立历史入口，撤销完成或从详情重开。未完成任务没有被自动删除。
- 重复系列只展示当前或下一次相关任务；旧版批量生成的未来实例不再刷屏。只在打开日历时间范围时按需生成相应实例；已有编辑、完成记录以及跳过记录不覆盖。
- 全天截止时间比较任务所属时区的日期；限时截止时间比较具体时间。逾期只是提示，没有自动改变任务状态。
- 日历默认显示未结束任务，可查看完成项；选择日期后打卡按选择日期记录。系列暂停或删除后停止未来提醒。
- 快捷记录可以继续转换成任务、笔记或日程；编辑重复任务时可以直接设置全天、具体时间、频率与优先级。

## 视觉复核

参考 UI UX Pro Max 2.15.0 中的生产力工具设计、信息层级、对比度、触控面积及间距规范：灰白中性色、单一低饱和强调色、轻量卡片、弱分隔线，清晰的主副文字层级；日常首页强调任务完成和打卡，减少重复按钮；底层仍采用系统字体、可自定义主题和响应式工作空间。逾期同时使用文字和颜色，不以颜色作为唯一状态信号。

## 验证与仍需完善

任务投影、全天截止、定时截止、缓存重复任务、暂停、长期重复规则增加了回归测试。保留原有加密备份、搜索、日历周期等测试。完整真机验收仍需进行；详见设计与验收文档中索引、积木细节、字体、统计和系统备份等剩余事项。此版不是 v1.0 正式验收版。
